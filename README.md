히토미 다운로더(https://github.com/KurtBestor/Hitomi-Downloader) 용 코네(kone.gg) 스크립트

사용방법
1. 다운로드 받은 파일의 압축을 풀고
2. 히토미 다운로더 - 설정 - 플러그인 - [+] 버튼 눌러서 추가
3. 다운로드 받을 URL 입력 후 다운로드

참고사항
1. DPI 우회를 켠 경우 오류 가능성 있음.
2. 로그인 오류나면 쿠키를 추가해주거나 열쇠버튼 눌러서 내장브라우저로 로그인 및 사이트 내 nsfw 설정 변경.
3. 같은 게시글을 다시 실행하면 이미지, 동영상, HTML을 모두 새로 받습니다. 파일별로 임시 이름으로 다운로드한 뒤 성공한 파일을 기존 이름으로 교체하므로, 미리 파일을 지울 필요가 없습니다.
4. 게시글에서 빠진 과거 첨부파일은 자동 삭제하지 않습니다. 제목이나 분류가 바뀌면 기존 폴더 이름 규칙에 따라 다른 폴더에 저장될 수 있습니다.
5. 코네콘은 로그인 쿠키/Range 없는 별도 요청으로 먼저 받아 저장합니다. 연결/읽기 제한은 3초이며 게시글당 8초의 시도 예산과 크기 제한을 둡니다. 실패한 콘은 `[코네콘 저장 생략]`으로 표시하고 일반 이미지와 HTML은 계속 저장합니다. 예산은 요청 시작/수신 사이에 확인하므로 DNS/연결/읽기 대기까지 포함한 엄격한 전체 시간 상한은 아닙니다.
6. 코네콘을 아예 받지 않으려면 스크립트 상단의 `DOWNLOAD_STICKERS = False`로 바꾸고 플러그인을 다시 불러오면 됩니다. 기본값은 `True`입니다. 기존 로그인 세션, KIO/Transfer.it 후처리 훅은 변경하지 않습니다.
7. 폴더명과 HTML/MHTML 파일명 앞의 `[카테고리]`를 빼려면 상단의 `INCLUDE_CATEGORY_IN_TITLE = False`로 바꾸고 플러그인을 다시 불러오면 됩니다. 기본값 `True`는 기존 동작을 유지합니다. HTML 내부 카테고리 정보, 원래 제목에 포함된 문구, 이름 끝의 게시글 ID는 그대로 보존합니다. 옵션 변경으로 저장 폴더가 달라질 수 있으며 기존 폴더는 자동으로 이름을 바꾸거나 삭제하지 않습니다.
8. 2026-11-07: 코네의 새 본문·댓글 구조를 지원합니다. 히토미에서 기존 코네 플러그인을 이 `kone_scrap.hds`로 다시 불러오세요. 구형 게시글 구조와 기존 저장 옵션, KIO 등 후처리 훅은 그대로 유지합니다.
9. 같은 날 댓글을 읽을 때 히토미의 페이지 이동 함수 `next()`와 충돌하는 문제를 수정했습니다. `next() takes from 0 to 1 positional arguments but 2 were given` 오류가 나면 수정된 플러그인을 다시 불러오세요. 로그인 방식은 바뀌지 않았습니다.
